Dynamic Content

Page Rewrites the Root Element

Each button does to <html> what some sites do on a theme switch or a client-side navigation. Emoji must keep rendering with Noto afterwards, including ones added with "Add dynamic emoji" above.

Body Replacement

Swaps <body> for a new element, the way Turbo Drive navigates. Emoji in the new body, and ones added to it afterwards, must render with Noto too. Reload to return to this page.

Text Nodes the Page Keeps Using

Frameworks keep the text nodes they created. The first button writes a new value to such a node through nodeValue: the box must show exactly that value, with the emoji in Noto, on every click. The second button takes the node out of the page and puts it back on the next click, which must not raise an error or leave any text behind.
